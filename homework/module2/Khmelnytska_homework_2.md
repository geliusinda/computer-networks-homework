Домашнє завдання №2
Тема: Транспортний рівень та служби мережі

Завдання 1. Аналіз відкритих портів

Команда: ss -tuln

- TCP - порт 53 (DNS), стан LISTEN
- UDP - порт 53 (DNS), стан UNCONN
- UDP - порт 323 (chrony), стан UNCONN

Порт 53 використовується для DNS, а порт 323 - для керування службою синхронізації часу. TCP очікує на з'єднання у стані LISTEN, а UDP показує UNCONN.

Завдання 2. Аналіз процесів, що слухають порти

Команда: sudo ss -tulpn

- Процес: systemd-resolved
- PID: 93
- Порт: 53 (TCP та UDP)

- Процес: chronyd
- PID: 254
- Порт: 323 (UDP)

systemd-resolved обробляє DNS-запити, а chronyd відповідає за синхронізацію часу.

Завдання 3. Перевірка TCP-з'єднання

Команда: nc -vz google.com 80

- Тип з'єднання: TCP
- Порт: 80 (HTTP)
- IP-адреса сервера: 172.253.115.100
- Результат: succeeded!

TCP-з'єднання з google.com через порт 80 успішно встановлено.

Завдання 4. Порівняння TCP та UDP

Команди:
nc -u -vz -w 3 8.8.8.8 53
nc -vz -w 3 8.8.8.8 53

- UDP, порт 53: succeeded!
- TCP, порт 53: succeeded!

TCP підтвердив встановлення з'єднання. UDP працює без встановлення з'єднання, тому повідомлення succeeded! не гарантує, що сервер отримав запит чи відповів. TCP забезпечує надійну передачу даних, а UDP не гарантує доставку.

Завдання 5. DNS резолвінг

Команда: nslookup github.com

- Домен: github.com
- IP-адреса: 140.82.114.3
- DNS-сервер: 10.255.255.254

DNS-сервер повернув IP-адресу для домену github.com.
