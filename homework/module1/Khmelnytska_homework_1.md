Домашнє завдання №1
Тема: Основи комп'ютерних мереж

Завдання 1. Дослідження мережі

Команда: ip a

- Інтерфейс: eth0
- Тип підключення: віртуальний Ethernet (WSL2)
- MAC-адреса: 00:15:5d:63:c3:54
- IP-адреса: 172.21.36.240 (3-й рівень OSI)
- Маска: 255.255.240.0 (/20, 3-й рівень OSI)
- Gateway: 172.21.32.1
- Broadcast: 172.21.47.255
- Hosts: 4094
- Адреса мережі: 172.21.32.0

Завдання 2. Дослідження маршрутизації

Команда: ip r

- Шлюз за замовчуванням: 172.21.32.1
- Інтерфейс: eth0
- Протокол маршруту: kernel
- Локальна мережа: 172.21.32.0/20

Маршрути додані ядром Linux (kernel). За результатом команди неможливо точно визначити, яким способом було отримано IP-адресу.

Завдання 3. Знаходження публічної IP-адреси

Команда: curl ifconfig.io

- Публічна IP-адреса: 52.124.41.225
- Локальна IP-адреса: 172.21.36.240
- Чи однакові адреси? Ні.

Локальна IP-адреса використовується всередині віртуальної мережі WSL2, а публічна - для виходу в інтернет. Адреси відрізняються через використання NAT, який дозволяє декільком пристроям або віртуальним середовищам використовувати одну публічну IP-адресу.
